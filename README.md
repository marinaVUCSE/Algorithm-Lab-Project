# MediRoute
### Medicine-Based Nearest Pharmacy Finder

## About the Project
MediRoute is a C++ project that helps users find the nearest pharmacy where their required medicine is available.

Users enter a medicine name, and the program finds the nearest pharmacy from Varendra University.

## Main Features
- Search for medicine by name.
- Find pharmacies that have the medicine.
- Show the nearest pharmacy.
- Calculate the shortest distance.
- Show the shortest route.
- Display pharmacy name, address, and phone number.

## Algorithm Used
- Dijkstra's Algorithm – To find the shortest distance and route.

## Data Structures Used
- Class
- Vector
- Graph (Adjacency List)
- Priority Queue
- Array

## Programming Language
- C++

## How to Run
1. Open the project in VS Code.
2. Compile `Main.cpp`.
3. Run the program.
4. Enter a medicine name.
5. See the nearest pharmacy and shortest route.

## Starting Location
Varendra University, Rajshahi.
